## FakeOS
> A terminal-based fake operating system built in Python.

## Features
- CLI Interface
- Guest and Root Accounts
- Todo Application
- Game
- Calculator
- Built-in Tools
- Filesystem (Coming soon in ZFS.py)

## Installation
```bash
git clone
https://github.com/xarvynx/fakeos.git
cd fakeos
python3 core.py
```
## Commands
--Available Commands Are:

- help
- exit
- ls
- cd
- whoami
- su
- calc
- guessr
- time
- neofetch
- todo
Fun commands (doesn't affect host pc)
- rm -rf /
- hacknasa


## Modules - 
- core.py (Brings Everything Together)
- games.py (games, etc.)
- utils.py (basic utilities)
- tools.py (tools like calculator, todo , etc.)
- ZFS.py (FileSystem , Coming Soon)
- config.py (Current User for root related tasks)

## REQUIREMENTS
- Python 3.x
- Linux/ Windows/ macOS
